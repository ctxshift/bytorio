Sunline Sprint

An original eight-kart perspective racer in both Bytorio SDKs.

  • Odin · CPU default / opt-in GPU
  • Luau · CPU default / opt-in GPU

WASD/arrows drive. Space hops into a drift; alternate steering, then release for a mini-turbo. E uses a collected turbo. Q switches resolution. Hold Space and press Q to cycle automatic LOD, low detail and high detail. R restarts.

Time your acceleration near the end of the countdown for a launch boost. Three laps; the minimap shows all eight racers.
