Riverside — a world beyond the frame

A cottage, leafy tree, irregular cobbled path, rabbit adventurer and red bridge over a winding stream. Compare direct rendering against a filtered 1080p render, using the same geometry, lighting and moving camera. No scoreboard.

Click the view, then use WASD to move the rabbit, arrow keys to pan, and Q/E to orbit. Pause motion to toggle quality at exactly the same pose. Supersampling averages 3×3 or 6×6 samples in linear color space before producing a true 640×360 or 320×180 game image. Final enlargement uses nearest sampling. Native size shows one canvas pixel per CSS pixel; high-DPI screens can use more than one device pixel per CSS pixel.

Smooth pan presentation keeps a snapped game grid with one pixel of overscan, then moves nearest-sampled blocks at a higher integer canvas scale using the residual camera offset. It applies to snapped, sprite and surface modes; native-size view disables it. The canvas gains presentation pixels, not scene detail. A fractional CSS fit can still rescale those pixels; use Actual 1920-pixel presentation for an integer CSS scale at normal browser zoom. Rotation still changes the view; this toggle stabilizes panning only. Redrawing at a camera snap boundary can still change rare edge or depth samples in the 3D scene.

Rabbit surface samples stores fixed object-local positions, normals and baked face colors once. Rotating the rabbit or camera reprojects the same samples as grid-aligned square splats with depth testing. Only the rabbit uses this representation. It is a rotation experiment, with approximate silhouettes, overlapping splats and possible gaps or depth artifacts; it does not guarantee invariant pixels. Compare Q/E orbiting with Rabbit sprite.

Pixel-snapped 3D aligns rendered camera and rabbit positions to the output grid without changing gameplay positions. Rabbit sprite captures the rabbit separately on a stable local grid, filters its color and coverage, and places it at whole pixels with depth occlusion. Its capture is reused during translation and refreshed when facing, camera angle or resolution changes. Supersampling still controls the world background. Rotation changes the sampled view; these modes do not promise rotation-invariant pixels.
