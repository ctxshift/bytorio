# Contributor documentation

These low-level documents are for people changing Bytorio's runtime, SDKs,
formats or tooling. They cover contracts and verification, rather than teaching
someone to make their first game. Game authors should start with
[Getting started](getting-started.md) and the [SDK guide](../sdk/README.md).

- [Console build and test setup](development.md)
- [Resource lifecycle and conformance examples](language-examples.md)
- [Capability negotiation and conformance](resource-profile.md)
- [Typed resource specification](resource-av-spec.md)
- [Legacy cartridge ABI specification](cartridge-spec.md)
- [Compact 3D and host rendering reference](compact-3d.md)

The source checkout also contains [architecture decisions](adr/README.md),
[internal measurement reports](internal/README.md) and the
[CLI distribution plan](internal/cli-distribution.md). These contributor records
are not part of the website's game-author handbook.
