# Support Luau and Odin for cartridge authoring

Support Luau as the default game language and Odin for authors who want explicit
data layout and allocation control, so choosing the console does not force one
programming style on every game author.
Both SDKs target the same console services and portable capability profiles;
maintaining two authoring interfaces and verifying their parity is the cost of
that choice.

Authoring details: [SDK guide](../../sdk/README.md).
